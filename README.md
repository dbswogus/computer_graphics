# 간단해진 편집기 사용법

Node 설치나 npm 명령 없이 editor/index.html을 열어 사용합니다.

- 상단 작업 선택: 맵 만들기 / 꾸미기·물리 / 담당별 저장.
- 테스트: 현재 프로젝트 플레이.
- 파일·배포: 프로젝트 백업(JSON), 불러오기, 타이틀 미리보기, release ZIP 내보내기.
- 맵 관리: 맵 추가·복제·삭제·순서 변경·예제·전체 비우기.
- 왼쪽 도구: 선택/바닥/지우개는 빠른 버튼. 나머지 블록은 선택 목록에서 고릅니다.
- 꾸미기·물리: 필요한 탭만 엽니다. 에셋을 고른 뒤 활용 목록에서 작업을 선택하고 적용합니다. 종류별 외형 설정은 그대로입니다.
- 담당별 저장: UIConfig.js · 유리 / MapConfig.js · 다유 / PhysicsConfig.js · 재현. 자기 파일만 내보내 editor/src/config에 교체하고 브랜치로 합칩니다.

main에 합친 뒤 페이지 새로고침 → 담당별 저장에서 '현재 폴더 소스로 초안 교체' → 테스트 → 파일·배포에서 'release ZIP 내보내기'를 사용합니다. 내려받은 ZIP을 풀어 release 폴더의 내용으로 교체하면 됩니다. 브라우저에서 기존 폴더를 자동 덮어쓰지는 않습니다.

원래 기능과 전체 프로젝트 백업, 로컬 에셋, 효과음, 담당별 설정을 유지했습니다. 자세한 설명은 사용 방법을 펼쳐 보세요.
